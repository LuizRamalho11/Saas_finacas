# Decisões de arquitetura (ADRs)

Uma decisão por arquivo. Para mudar uma decisão, crie um novo ADR que substitui o anterior e marque o antigo como "Substituída por ADR-NNN".

## Modelo para novos ADRs
```markdown
# ADR-NNN — Título
- **Status:** Proposta | Aceita | Substituída por ADR-NNN
- **Data:** AAAA-MM-DD
## Contexto
## Decisão
## Consequências
```
